Modular Retro Terminal - Isolation Test Page

This page uses a completely blank, un-themed backdrop to verify style isolation.

  • Scroll Past It: The terminal is positioned in the document flow (position: absolute). Scroll down to see it left behind.
  • Draggable Anywhere: Drag the top bar (dungeon-crawler-text) to place it anywhere on the page—even after scrolling down.
  • Static Display: User input is disabled; it cleanly shows loremaster > | with a blinking cursor.
  • Square Form Factor: Styled in a clean 1:1 aspect ratio matching the viewer's grid styling.
  • Unhighlightable: Text selection is disabled (user-select: none).
